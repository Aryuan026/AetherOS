# 陪伴素材无向量召回验收

日期：2026-07-28
状态：本地候选代码 Green；没有提交、推送或部署

## 验收到底在验什么

角色扮演不存在“验证完毕后永不 OOC”。这条链路只在原则上改善模型收到的
条件分布，让它更容易抓住角色自己的注意方式、判断节奏和行动可能性，同时保留
忽略素材、转题、沉默、拒绝、改变表达和选择工具的空间。

三类检查不能互相冒充：

1. **代码门禁**检查 scope、surface、事实权限、预算、去重、回执和合法零素材；
2. **API 侧复读**把最终 System Prompt 当作模型真正收到的上文，判断是否出现
   重复训话、负向指令堆叠、固定回应流程或工具能力被压住；
3. **自然体验反馈**观察角色是否像、是否腻、是否在多轮后收敛成套路。玩家不需要
   看见后台素材，也不负责证明 Prompt 正确。

离线 A/B、去名判断和评分只能帮助暴露倾向，不能取得产品裁决权，更不能因为某个
格子分数不高就把一整类素材长期锁住。

## 909 条短信怎样“物尽其用”

“物尽其用”不是 909 条逐条进入 Prompt，也不是强求每条都形成独立记录。它指：

- 有辨识度的表达范围进入 `language_fingerprint`；
- 经过复核的稳定角色信息进入相关检索 detail，必要时再由更高权威晋升角色卡；
- 开场形态和主动缘由进入 Call / 主动来信 / 场景开场候选；
- 场景纹理进入 Meet / Date / ScenePlan 的 affordance；
- 重复来源共同支撑同一语义簇，提高稳定性而不重复递送；
- 只有损坏、无法抽象或泄露风险无法消除的内容才隔离。

原短信不进入运行时 Prompt。运行时只接收已经提纯、非逐字、角色或关系作用域
明确的语义参考。普通 Chat 每轮最多一条；其他入口未来可在各自预算下使用
1–3 条。选择少不等于素材浪费：没有被本轮选中的材料仍然保留为未来场景的可能性。

## 这次完整 Prompt 复读

本轮使用真实 `ChatPrompts.buildSystemPrompt()`、祁煜/黎深内置角色卡、默认挂载
资料和生产 selector 拼装了两份代表性长上文；另外三位只接受窄命中与零素材探针，
不因缺少同等成熟的人类校准角色卡而伪造完整表现结论：

| 角色 | 默认资料包 | 资料正文字符 | 最终 System Prompt 字符 |
| --- | ---: | ---: | ---: |
| 祁煜 | 9 | 9,232 | 13,347 |
| 黎深 | 9 | 8,446 | 12,456 |

这不是 token 费用承诺，只是同一代码版本下的相对密度观察。真正明显的压力来自：

- 默认世界书和角色资料量很大；
- 原 Chat 通用质量规范又重复要求细节、主动生活、独立判断和打破安慰结构；
- 历史、时间与语音边界使用了较密集的禁止式表达；
- 单条角色素材位于这些大段规则中间，既可能被淹没，也可能与通用规则重复。

本轮因此没有删素材，也没有修改内置角色卡，而是：

- 把素材从“本轮可选回应动作”改为“本轮角色侧参考”；
- 明确它帮助模型决定角色可能注意什么，不是当轮任务、事实、关系或当前动机；
- 把普通 Chat 的通用质量教程缩成三条开放原则；
- 将长间隔和旧日档案改成中性的时间/事实分层，不预先列出应当产生的情绪；
- 把每轮一条角色参考放到 System Prompt 末端，临近当前消息，但保留可忽略声明；
- 补上“你今天都做了什么”这类自然说法对角色自生活的识别。

默认世界书仍然是完整 Prompt 中最大的密度来源。这次只记录风险，没有顺手重构；
未来应在世界书自己的路线里做相关性和预算治理，不能让陪伴素材 selector 私自接管。

## 站在模型位置的实际感受

祁煜面对“水坑里的红叶”时，末端参考只把注意力轻轻推向颜色、反差和当下感官。
角色仍可逗人、联想到画、只问一句、转去说自己的事或根本不采用这个角度；它没有
要求输出海洋比喻、邀请用户或复刻某条短信。

黎深面对“今天不去了，下次吧”时，末端参考允许平静确认、简短反问或克制玩笑。
它没有要求问诊、解决问题、安排下一次，也没有把拒绝解释为关系事件。真正的语气
仍主要来自角色卡与现场。

这两个样本不是标准答案。它们只回答一个后台问题：读完上文后，模型是否获得了
更像角色的落脚点，同时仍觉得自己可以选择别的合理回应。当前答案是“可以”，且
比修改前少了明显的流程压力。

## 仍然保留的边界

- Call、主动来信与 Date / Meet 的稳定层消费者已接；ScenePlan 的 motive / affordance 裁决仍 HOLD；
- 909 条素材的内容分析与归类由专门工位完成，当前运行树只接收结案 artifact 的
  非逐字 active records；disabled / withheld 处置不能被运行树擅自翻案；
- 浏览器/APK embedding producer / store / toggle 继续 HOLD；可信 rank seam 与自动 lexical fallback 已准备；
- 三位窄 voice 只在 explicit premise / tradeoff 下命中，普通括号动作与“怎么办”不再
  误触；每条有 6 小时 cooldown，邻接轮不重复注入；
- 不增加玩家可见的测试入口。玩家最终看到的只有自然角色表现。
