# 深空书持续完善与入库标准

深空书目前是**可运行、但尚未结案**的资料库。现有条目可以参与运行，
但不能因为已经进入内置库，就被视为资料已经抓完、事实已经穷尽或文字已经不可修订。
后续主线、逸闻、卡面、传说、活动与世界资料补齐后，仍需按本合同复核、去重和升级版本。

## 一、能力真相

资料必须区分以下阶段，不能互相冒充：

`已找到来源 -> 已提取证据 -> 已核对归属 -> 已编写世界条目 -> 已通过模型上文审读 -> 已进入内置库 -> 已在相关请求中递送`

- WorkBuddy 或网页抓取完成，只代表“已找到来源”。
- 审校 artifact 完成，只代表“已提取证据并标注归属”。
- 只有最终世界条目通过模型上文审读，才可以进入内置库。
- 进入内置库也不等于每轮递送，更不等于当前已经发生。

## 二、一个概念只有一个定义 owner

每个公共概念只能由一条基础世界资料负责定义。角色资料只能补充：

- 这个角色知道什么；
- 在哪一场事件中接触过它；
- 角色隐瞒、判断或采取了什么行动；
- 这条线仍有哪些尚未解开的因果。

角色资料不得重新发明公共概念的定义，也不得把“携带某种能量”写成
“就是这种能量核心”。若两个来源使用相近名词，必须先核对其关系，再写入。

当前已确认的示例：

- **以太芯核**由基础世界资料负责定义；
- 沈星回主线中的废弃能源基地与 7 号禁猎区样本，是同一种被改造的芯核；
- 这类改造芯核携带来自以太芯核的能量，但不因此等同于以太芯核；
- 沈星回知道这层联系，协会当时只确认能量强大且无法探知，并不知道以太芯核的全貌。

## 三、原作连续经历、独立世界线与自建拓展分仓

- 同一现世履历按真实时间顺序保存，未被本轮选中只代表没有展开细节，不能否认经历存在。
- 主线、逸闻、卡面、传说、活动先按来源分车道，再判断是否属于同一连续经历；不能仅按页面栏目拆成互斥世界线。
- 菲罗斯、烬城等独立世界线分别保存，身份、关系、NPC、地点与因果不得跨线自动合并。
- 原作终局可以作为作者/主持参考，但不能偷偷写进开放世界前提，替玩家预定结局。
- Fate 式多世界线兼容、现代异常治理等人类自建内容进入独立拓展，不改写 Evol、猎人协会、临空市、菲罗斯等原作概念。

## 四、进入模型上文前的文字标准

世界书正文必须像一段可以直接交给扮演模型理解的世界事实，而不是给开发者看的处理报告。

### 必须具备

- 足以驱动后续生成的具体人、组织、地点、物件、事件与因果；
- 谁知道什么、谁不知道什么，以及秘密在什么事件后才可能揭开；
- 已确认事实与仍未确认问题的清晰边界；
- 对独立世界线，提供可继续行动的势力、目标、冲突与未决空间，而不是只有剧情梗概；
- 对角色履历，说明经历如何影响其判断、隐瞒、责任或行动，不把人物压成一组标签。

### 禁止进入正文

- “可游玩、玩法用途、适合展开、需要启用、当前挂载、本轮递送、资料包、世界书”等产品或编译器术语；
- “这是某角色较早的一段、这一阶段可以展开……”一类审校摘要；
- 为了显得资料完整而补出的年份、组织层级、人物关系、结局或因果；
- 把 `{{user}}` 自动写成已经经历原作关系，除非身份、路线与关系阶段已经明确建立；
- 把 activation hint、UI 分类、来源强弱、审校意见混进模型正文。

分类、排序、启用提示和来源状态只服务于资料治理与 UI，不随正文一起递送。

### 系统主持生成时的统一口径

本节不只约束维护者手工编写的内置资料，也约束 AetherOS 内部所有会生成世界书正文的系统主持入口。
当前玩家资料智能整理与剧情确认后的世界生长建议，共用
`WORLDBOOK_MODEL_BODY_AUTHORING_GUIDANCE`；后续新增生成器也必须复用该口径，不能另写一套更空泛的摘要提示。

系统主持的工作是把证据编译成模型可以继续使用的世界知识：补足语义结构，不补造事实；写清行动与因果，不替角色和玩家决定未来；保留不确定性，不用产品术语掩盖资料不足。最终结果仍由玩家预览、修改和保存，AI 生成本身不取得事实写入权。

## 五、入库门

一条内置深空资料只有同时满足以下条件，才可标为 model-ready：

1. 具备可追溯的原始来源或 owner 授权的人类原创来源；
2. 逐条事实已标注语义 owner，没有和基础世界书或其他角色包重复定义；
3. 主线、IF、卡面、逸闻、活动与自建拓展没有串线；
4. 关系事实有阶段门，秘密有知情范围；
5. 正文足以直接进入模型上文，不含产品说明和审校摘要；
6. 以“模型收到这段后会怎样理解自己、世界与当前关系”为视角完成审读；
7. 通用 Worldbook projector 具备少量代表性的正向与负向回归夹具，证明相关内容能取到、无关话题与错误身份不会误取；这是运行时算法的统一测试，不是每条素材的独立审批手续；
8. 内置版本已递增，旧本机记录可以被同 ID 新版本安全刷新。

证据不足的条目可以保留在私有审校区继续补抓，不得用空泛梗概占据正式内置条目。

## 六、后续完善记录

每次新增来源后，都要留下：

- 新增了哪些来源车道；
- 哪些事实被补强、纠正或撤回；
- 哪个概念的 semantic owner 发生变化；
- 哪些条目仍 unresolved；
- 最终模型正文与上个版本相比改变了什么；
- 哪些入口已经验证，哪些仍为 HOLD。

五位男主都按同一标准结案，但不能复制彼此的角色结论。祁煜、黎深已有的聚合剧情增强书仍需按真实路线继续拆分；
沈星回当前版本也只是第一轮可运行稿，主线、逸闻、卡面与独立世界线来源继续补齐后必须再次审读。
